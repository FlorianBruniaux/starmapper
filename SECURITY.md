# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in StarMapper, please report it **privately** — do not open a public GitHub issue.

**Contact:** florian@bruniaux.com  
**Subject:** `[SECURITY] StarMapper — brief description`

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

I will acknowledge your report within **72 hours** and aim to release a fix within **14 days** for critical issues.

Public disclosure is welcome after the fix is shipped, or after 90 days if no fix has been released.

## Scope

In scope: the StarMapper web application at starmapper.bruniaux.com and its API routes.  
Out of scope: GitHub infrastructure, Vercel, Neon, third-party geocoding services.

## Thank You

Security research is appreciated. There is no bug bounty programme, but responsible disclosures will be credited in the release notes if you wish.
